# dotPaint screenshots

실제 Windows에서 dotPaint **v1.3.3**을 실행해 촬영한 PNG를 이 폴더에 넣으세요.

권장 파일 이름:

- `main-light.png`: 메인 화면, 라이트 테마
- `main-dark.png`: 메인 화면, 다크 테마
- `stretch-skew.png`: 늘이기·기울이기 대화상자 (양방향 px↔%)
- `field-visualization.png`: 전기장/자기장/중력장 중 실제 실행 캡처
- `shapes-3d-4d.png`: 3D/4D 도형 그리기 화면

촬영할 때 사적인 파일 경로, 계정, 학생 정보, 비공개 자료가 보이지 않는지 확인하세요. 나중에 이미지가 추가되면 저장소의 `README.md`와 `docs/index.html`의 이미지 링크를 켜세요.
