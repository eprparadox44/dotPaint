Windows desktop graphics editor · v1.3.3

가볍게 그리고,
정확하게 표현하다.

XP 그림판의 간결함에 수식, 도형, 인덱스 팔레트와 물리 시각화 도구를 더한 Windows용 독립 그래픽 편집기입니다.

↓ 최신 버전 다운로드소스 코드 보기

주요 기능

✏️ 그림판 기본 도구

브러시, 선, 도형, 선택, 채우기, 실행 취소와 편집.

🎨 색상·팔레트

RGB 색 편집 및 16색·256색 인덱스 팔레트.

∑ 수학·기하

수식과 함수 그래프, 3D/4D 도형 시각화.

⚡ 물리 시각화

전기장, 자기장, 중력장 등을 정밀하게 그리는 도구.

📐 정밀 크기 변경

백분율↔픽셀 자동 연동, 소수 입력, 결과 크기 미리보기.

🌗 라이트·다크

다양한 작업 환경을 위한 테마 지원.

프로그램 스크린샷

v1.3.3 실제 실행 화면을 준비 중입니다. 캡처는 GitHub의 docs/screenshots에 추가됩니다. (현재 이미지를 임의로 생성하거나 다른 버전 화면을 대신 사용하지 않았습니다.)

다운로드 안내

Windows 64비트(x64), 32비트(x86) 실행파일과 통합 ZIP은 GitHub Releases의 Assets에 있습니다. Windows용 네이티브 프로그램으로, 이 웹페이지에서 직접 실행되지는 않습니다.
