1.2.32 핵심 변경:
- 마지막으로 사용한 다크/라이트 모드를 Windows 사용자 설정 폴더에 저장
- 다음 실행의 주 창 생성 전에 저장값을 읽어 첫 화면부터 같은 테마로 표시
- 테마 전환 직후와 정상 종료 시 모두 저장하여 마지막 상태를 안정적으로 보존
- 저장값 없음·손상·읽기 실패 시 기존 기본값인 라이트모드로 안전하게 시작

1.2.31 핵심 변경:
- 늘이기/기울이기 창에서 Tab·Shift+Tab으로 네 숫자 입력칸, 안티에일리어싱, 확인·취소를 순환
- 캔버스 크기 창에서 Tab·Shift+Tab으로 가로·세로, 전형적인 크기 목록, 확인·취소를 순환
- Windows 공용 색 편집 창의 초기화 뒤 밝은 템플릿 재적용을 지연 다크 새로고침으로 차단
- 색 편집 창 제목줄·배경·글자·입력칸·버튼은 다크화하고 실제 색 견본·계산은 네이티브 엔진 유지

1.2.30 핵심 변경:
- 자유 선택, 색 영역 선택, 동일 색 전체 선택의 복사 이미지에서 마스크 밖 픽셀을 완전 투명 처리
- Windows PNG 클립보드, dotPaint 클립보드 기록, 고정 PNG에 실제 선택 픽셀만 보존
- 사각 선택·전체 선택, 잘라내기·이동·붙여넣기 및 기존 Mask 윤곽 동작 유지

1.2.29 핵심 변경:
- 다크 보조창을 숨긴 상태로 생성하고 네이티브 프레임·최종 레이아웃 확정 뒤 처음 표시
- 최초 표시 직전 전체 클라이언트를 무효화·즉시 그려 제목 표시줄 아래 버튼 조각 잔상 제거
- 제목 표시줄 보정 타이머의 보이는 창 SWP_FRAMECHANGED 재호출 제거
- 수식, 함수/그래프, 다차원 도형, 장, 도움말, 세 라이브러리, 정보 창에 공통 적용

1.2.28 핵심 변경:
- 대칭 이동 및 회전 창에 다른 소형 대화상자와 동일한 모달 대화상자 프레임 적용
- 라이트·다크 DWM 테마 적용 뒤 실제 클라이언트를 재측정해 756 × 585px로 보정
- 전체 실측 클라이언트를 UI 배경색으로 먼저 채워 우측·하단 검은 미도색 영역 제거
- 이미지 변환 계산, 미리보기, 버튼 배치와 라이트·다크 팔레트 유지

1.2.27 핵심 변경:
- Windows 11 다크 보조창 제목 표시줄을 실제 클라이언트 경계까지만 그려 하단 잔상 제거
- 수식 편집기 하단 카테고리 팝업의 메뉴 측정·그리기 메시지 처리 복구
- 대칭 이동 및 회전의 회전판 채움색을 다크 팔레트로 변환하고 12px UI 글꼴 적용
- 늘이기 및 기울이기의 안티에일리어싱 제목과 버튼을 12px·평면 네모 스타일로 통일
- 캔버스 크기의 확인·취소를 평면 버튼으로 바꾸고 하단 설명 삭제
- 도구·색상표·클립보드·히스토리 등 도킹 제목을 11px에서 12px로 확대

1.2.26 핵심 변경:
- 장 그리기의 모든 네이티브 컨트롤에 맑은 고딕 12px 조밀 UI 글꼴 적용
- 다차원 도형의 w 회전 라벨 폭을 확보하고 하단 네 열을 창 폭에 맞춰 계산
- 도구·색상표·클립보드·히스토리 등 16px 도킹 헤더에 11px 전용 제목 글꼴 적용
- 장 편집기와 도킹 제목 글꼴의 생성 실패·창 종료 GDI 핸들 수명 관리
- 실제 장·다차원 도형·캔버스 렌더링과 라이트·다크모드 동작 유지

1.2.25 핵심 변경:

- 세 보조창의 버튼·라벨·콤보·입력칸에 맑은 고딕 12px 전용 UI 글꼴 적용

- 라이트·다크모드 평면 네모 버튼과 기존 기능·렌더 결과 유지

1.2.24 핵심 변경:

  나머지 수식 버튼과 같은 단일 테두리 네모 상자 스타일 사용
- 눌림은 1픽셀 이동과 어두운 바탕으로, 키보드 포커스는 테마별 강조선으로 표시

1.2.23 핵심 변경:
- Windows 공용 색 편집 대화상자에 다크모드 전용 훅 적용
- 제목 표시줄, 테두리, 창 배경, 라벨, 입력칸, 버튼, 스크롤 UI를
  dotPaint의 다른 다크 대화상자와 같은 팔레트로 통일
- 기본색·사용자 지정색·색상 스펙트럼·명도 막대는 실제 색을 그대로 유지
- Windows 원본 ChooseColor 색 계산과 사용자 지정색 저장 동작을 그대로 보존
- 라이트모드는 기존 무훅 호출 경로를 유지

1.2.22 핵심 변경:
- 새 미리보기 요청이 오면 이전 전기·자기·중력 선 적분, 퍼텐셜 격자,
  마칭 큐브, 부피 및 면 렌더를 취소 토큰으로 조기에 중단
- 전기력선·중력장선과 중력 GPU 벡터 격자를 물리 장면별로 캐시
- 3차원 등전위 격자·밴드·세계 좌표 삼각형 메시를 카메라와 분리해 재사용
- 6배 고해상도 Mask 제거, 고해상도 BGRA 버퍼 풀 재사용
- 안정 미리보기의 중복 픽셀 복사 제거, 같은 프레임의 배경 합성 버퍼 재사용
- 배포판만 10,000,000바이트 크기 기준 적용; 개발판은 상세 진단을 위해 제한 제외

1.2.21 핵심 변경:
- 장 그리기의 물체 이동과 슬라이더 조작 중에는 1배 물리 미리보기 사용
- 조작 종료 후에는 사용자의 부드럽게 설정에 따라 6배 최종 화면으로 즉시 재계산
- 실제 캔버스 삽입은 조작 중 정책과 분리되어 종전 6배 최종 품질 유지
- 연속 입력은 한 개의 실행 작업과 최신 한 개의 대기 작업으로 합쳐 과잉 계산 방지
- 다음 1배 작업이 대기 중이면 방금 끝난 1배 프레임을 표시하여 연속 조작 중 화면 정지 방지
- 최종 6배 결과는 정확한 최신 세대 번호가 일치할 때만 적용하여 오래된 프레임 덮어쓰기 방지
- 빈 3차원 등전위막 결과는 계속 폐기하고 마지막 정상 물리 프레임 유지

1.2.20 핵심 변경:
- 장 그리기의 부드럽게 렌더링을 2배에서 6배 면적 평균으로 강화
- 전기·자기·중력장선과 3차원 등전위막 윤곽의 짧은 선분을
  고해상도 연속 원형 획으로 그려 이음매·계단·1픽셀 끊김을 억제
- 3차원 등전위막도 정지한 최종 미리보기와 실제 삽입에서 6배 AA 적용
- 투명 BGRA 면적 평균을 CPU 여러 코어로 병렬 처리
- 부드럽게 끔은 기존 1배 픽셀 렌더링을 그대로 유지

1.2.19 핵심 변경:
- 포물면/쌍곡면, 말안장면, 블랙홀, 쌍원뿔과 원뿔곡선, 토러스,
  뫼비우스 띠, 2·3-스타인메츠, 120-셀, 600-셀, 클라인 병은
  조작 중 1배, 조작 종료 후 6배 AA 사용
- 나머지 도형은 조작 중과 정지 상태 모두 6배 AA 유지
- 부드럽게 끔에서는 모든 도형 1배
- 프로그램 자체의 정확한 BGRA 면적 평균, 병렬 축소, 버퍼 재사용 유지
